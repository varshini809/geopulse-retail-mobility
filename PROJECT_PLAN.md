# GeoPulse: Hyper-Local Retail Mobility Analytics

Infotact Solutions | Data Analytics Internship | Month 2 project

## Goal
Find out how foot traffic moves around store locations during the day.
Use this to judge where a new store should open, without taking
customers away from an existing store of the same chain.

## Draft plan by week
Week 1: Data setup
- Create mock data of anonymous phone location pings
  (device id, latitude, longitude, timestamp) that look like city movement.
- Design the SQL tables and load the data.
- Check the data for missing and wrong values.

Week 2: Store catchment areas and footfall
- Choose a few store locations and draw a catchment area around each.
- Count unique visitors per store per hour.
- Compare morning and evening traffic.

Week 3: Cannibalization check
- Find how many devices visit more than one store.
- Estimate how much traffic a new store would take from an old one.
- Build version 1 of the Power BI dashboard.

Week 4: Finish
- Freeze the data, improve the dashboard, write the report.
- Prepare the demo script and viva answers.
- Merge branches into main near the end.
